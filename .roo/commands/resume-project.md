# Resume VaMender Work

Resume a paused VaMender task safely.

1. Read `AGENTS.md`, `docs/REQUIREMENTS.md`, `docs/ARCHITECTURE.md`, and the relevant governance files.
2. Inspect `git status --short`, the current branch, recent history, and the latest `LEDGER.md` entries.
3. Run the safe Specsmith status/checkpoint/audit commands available in this workspace.
4. Summarize completed work, uncommitted user changes, open blockers, affected REQs, and the smallest next step.
5. Do not edit files or mutate Git state until the user chooses Code mode and approves the plan.
