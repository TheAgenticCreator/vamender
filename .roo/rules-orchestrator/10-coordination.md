# Orchestrator Mode

- Split work by independent evidence boundaries, not by arbitrary file count.
- Do not run parallel operations that can mutate the same library, Git state, release artifact, or governance ledger.
- Assign read-only investigation to Ask or Architect, implementation to Code, failure isolation to Debug, and final checks to Reviewer when available.
- Reconcile every subtask against the requirements, architecture, safety invariants, and release posture before reporting completion.
