# Session Protocol

1. Read `AGENTS.md`, applicable requirements, architecture, and recent ledger.
2. State the proposed scope and obtain approval for governance changes.
3. Run Specsmith preflight when a governed work item is needed.
4. Implement the smallest scoped change and preserve unrelated user work.
5. Update requirements/tests when behavior or evidence changes, then sync.
6. Run mapped automated checks and identify any required manual checks not run.
7. Run Specsmith gaps, orphans, audit, and change-set verification.
8. Append the outcome, requirement IDs, evidence, and residual risks to ledger.
