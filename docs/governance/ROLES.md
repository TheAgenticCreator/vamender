# Roles

- **Maintainer**: approves requirements, release-channel changes, risk
  acceptance, and tag publication.
- **Contributor/agent**: implements approved scope, maintains traceability,
  runs available evidence, and reports rather than hides unrun manual gates.
- **CI**: authoritative automated build, package, security, checksum, and
  release-artifact producer.
- **Beta tester**: runs manual acceptance only on a disposable or independently
  backed-up library and records the supported Windows/VaM environment.
- **User**: chooses library and backup roots, preserves authorized content, and
  maintains an independent tested full backup.
